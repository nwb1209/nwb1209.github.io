# nwb1209.github.io
部分AI agent的功能以及取得的效果,收获。
1. 豆包
用途：Python编程习题讲解、高数极限/矩阵知识点答疑、英语单词与长句翻译、文书写作修改、Arduino硬件项目排查问题、整理学习笔记。
效果：遇到难题可以即时得到分步解释；获得带详细注释的代码，快速定位报错；辅助完成写作任务，节省检索资料的时间，是日常最常用的学习助手。
2. 代码Agent
用途：编写、测试、简化Python代码；练习循环、素数筛、幻方、排序等课内编程题目；对比不同写法，理解算法逻辑。
效果：把复杂程序拆解成基础步骤，降低编程入门难度；学会排查语法错误、理解复合运算符、lambda等容易混淆的知识点。
3. 智能检索Agent
用途：查找硬件接线教程、GitHub Pages建站流程、云服务器使用说明、技术资料。
效果：快速拿到实操方案，规避新手常见错误；本次个人网站的搭建，就是依靠这类工具完成从注册仓库到部署上线的全流程。
 
二、使用收获
 
AI Agent是很好的辅助学习工具，可以大幅提升查阅资料、调试代码、理解新知识的效率，帮助我完成课程作业和课外实践（网页搭建、单片机实验）。
同时我也意识到：AI的输出需要人工校验。学习的核心是掌握思路，不能直接复制结果，要保持独立思考，验证每一个结论是否正确。
